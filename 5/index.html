Part 1.1 Implementing the Forward Process

The main principle behind diffusion models is image denoising. The assumption is that noise was added to the original image (timestep t for noisy image) and we want to iteratively denoise it until we get back to the clean image at timestep 0. Therefore, the first step towards denoising the image means we need to add Gaussian noise to the original. The equation for adding noise becomes square root of some noise coefficient times x_0 plus the square root of (1 - the noise coefficient) times some epsilon where epsilon follows a Gaussian(0, 1) distribution.

Part 1.2 Classical Denoising

If we simply try to "denoise" an image with a Gaussian, we will lose some of the noise along with the signal and the overall image will just be blurry.

Part 1.3 One-Step Denoising

A diffusion model, in this case a Unet, is trained to denoise images. However, if we try to denoise the image in one step, the algorithm will greatly hallucinate as you can see below. Here, I used part 1.1 to add noise to an image, then I passed it into the diffusion model to calculate a noise estimate, and reordered the terms from the equation in part 1.1 to extract x_0: the predicted image without noise.

Part 1.4 Iterative Denoising

When we iteratively denoise the image, on the other hand, the results look much closer to the original image. For this part, I skipped some timesteps to get the model to denoise more quickly, but the update equation consists of a weighted combination of the current estimate of the image with one-step denoising (from previous timestep t-1 to the current one t) plus the image at timestep t plus a variance term.

Part 1.6 Classifier-Free Guidance (CFG)

Hmmmmm....the generated images from part 1.5 didn't look very realistic. What we can instead do is shrink the pool of accepted images while greatly improving image quality. This is called Classifier-Free Guidance (CFG). Here, we will have two prompts that will create a conditional and an unconditional noise estimate for our image. The new noise estimate then becomes: unconditional noise estimate + gamma * (conditional - unconditional noise estimate). When we set gamma to be greater than 1, we can get high quality images. The conditional prompt for the images below was "a high quality photo" and the unconditional prompt was "" (null).

Part 1.8 Visual Anagrams

A visual anagram is an optical illusion where one image can encode multiple images. For example, in the images below, if you flip them across the x axis, they become a different image. To create this illusion, we need two noise estimates: one where the image is right side up, and one where the image goes through the network upside-down (and is then flipped right side up again so that it can be added together with the first to create the illusion). The result then becomes an average of those two image estimates.

Part 1.9 Hybrid Images

Hybrid images are another form of optical illusion where there are multiple images in one. In this case, there is an image with high frequency information (details) that can be seen up close and another with low frequency information that can be seen far away. Similar to part 1.8 we also again create two noisy image estimates, each with different prompts. To combine the two, we Gaussian blur one image and do image - Gaussian blur for the other image (to capture the high frequency information from the second).

Part 2.1: Adding Time Conditioning to UNet

To do flow matching, we need to introduce a time component into the UNet where the goal is to predict the flow going from a more noisy image to a less noisy image. We can do linear interpolation to approximate the image at some timestep t: $$x_t = (1 - t)x_0 + tx_1$$ where $x_0$ is the noisy image and $x_1$ is the clean image. $x_t$ can also be defined as a vector field of the position of our image estimate with respect to the positions of the clean and noisy images. When the field is differentiated with respect to t, we get a change in velocity or flow: $$\frac{dx_t}{dt}=x_1 - x_0$$ Finally, our loss will calculate the mean squared error between the flow prediction of the UNet and the actual flow $x_1 - x_0$. To implement this, I multiplied FCBlocks pictured below by the Unflatten result and result after the first UpBlock from the UNet architecture figure in part 1.1.

For better control of the generation results, I also added class conditioning to the UNet by implementing two more FCBlocks at the Unflattened and UpBlock1 layers. I also encoded the class condition vector as a one-hot vector where 10% of the time, the vector would be set to 0.

Part 2.6: Sampling from the Class-Conditioned UNet

Sampling from the class-conditioned UNet is similar to the classifier-free guidance from part 1. We have two model estimates: a conditional estimate that uses the one-hot class label corresponding to the given noisy image and an unconditional estimate where the one-hot vector is 0. The two estimates are then combined together to form the cumulative model estimate and iteratively denoise the input image. What happens if we get rid of the scheduler we used throughout part 2? Well there isn't much of a difference!
